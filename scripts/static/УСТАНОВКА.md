# LightFabric: установка статической сборки на веб-сервер 1С

Это цеховое приложение для планшетов и телефонов. Оно состоит только из файлов
(html, js, css), серверной части у него нет: данные берутся из HTTP-сервиса 1С
прямо из браузера. Node.js, база данных и прочее на сервере не нужны.

## 1. Куда положить

Папку `lightfabric` целиком положить на веб-сервер рядом с публикацией 1С
так, чтобы она открывалась по адресу вида:

    http://<сервер>/lightfabric/

Имя каталога менять нельзя: оно зашито в сборку. Если нужен другой каталог,
пересоберём под него.

Для IIS в папке уже лежит `web.config` (типы файлов для манифеста и шрифтов,
`index.html` как документ по умолчанию). Для Apache и nginx достаточно отдать
папку как статику, документ по умолчанию `index.html`.

## 2. Проверка с телефона в сети фабрики

1. Открыть в браузере телефона `http://<сервер>/lightfabric/`.
   Должна открыться страница входа.
2. В этой сборке 1С заменена заглушкой: логин любой (например, `цех_литейка`),
   пароль любой. Под логином `админ` появляются права администратора.
3. После входа открывается рабочее место цеха: смены, выработка, передачи.
4. Браузер предложит установить приложение на экран (на iPhone: «Поделиться»
   → «На экран Домой»). После установки оно открывается иконкой, как обычное
   приложение.

Если страница входа открылась, значит сеть и раздача файлов работают.

Про HTTPS: приложению он не нужен, по `http://` работает всё. Но без него
Chrome на Android не ставит приложение иконкой и не включает работу без сети,
а Safari на iPad ставит иконку без офлайна. Если HTTPS с нормальным
сертификатом поднять получится, планшеты получат обе возможности.
Сценарии на живой 1С проверяем на следующей сборке, уже с адресом сервиса.

## 3. Что нужно для боевой сборки

- относительный путь к HTTP-сервису 1С на этом же сервере (вида `/база/hs/lightfabric`);
- тестовые учётные записи 1С для входа;
- при необходимости другое имя каталога.

С этими данными сборка собирается заново командой
`npm run build:static -- --base /lightfabric --api /база/hs/lightfabric`,
и приложение начинает ходить в 1С вместо заглушки. Запросы идут на тот же
адрес, что и сама страница, поэтому настройки CORS не нужны.

## 4. Обновление

Заменить содержимое папки `lightfabric` новой сборкой. Открытые на планшетах
копии подхватят обновление при следующем запуске.
