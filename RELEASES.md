# Выпуски LightFabric для сервера фабрики

Первый раздел этого файла уходит в описание выпуска в GitHub Releases
(`.github/workflows/release.yml`). Новый выпуск: дописать раздел сверху,
поставить тег `v<версия>` и отправить его в GitHub.

Пометка «Нужна 1С» значит, что выпуск работает только после изменений
на стороне 1С, без них ставить не нужно.

## 2026.10.29-1

Нужна 1С: для удаления смены да, метод `DELETE /shifts/{id}`. Остальное
работает на нынешней 1С.

- Рабочее место: «Последние смены» за неделю со статусами, нажатие
  открывает смену; кнопка «Все смены и архив».
- Незакрытая смена прошлого дня подписана датой и бейджем «не закрыта»,
  кнопка «Закрыть смену за …»; она больше не прячет кнопку открытия
  сегодняшней смены с тем же номером.
- История: текущий месяц сверху, прошлые месяцы в разделе «Архив»,
  свёрнуты, раскрываются касанием, с итогами за месяц.
- Удаление смены-черновика (открытой, не отражённой в учёте) с
  подтверждением. Пока у 1С нет метода, приложение пишет об этом.

## 2026.10.28-1

Нужна 1С: нет.

- Смена, строка выработки: «Вид работ» и «Продукция» выпадающими списками
  с поиском вместо кнопок. На справочниках 1С их десятки, кнопками искать

  регистра и ё/е.
- Продукция без артикула показывается без запятой в начале названия.

## 2026.10.27-2

Нужна 1С: нет. С v0.4 на стороне 1С проверка работает для всех получателей.

- Новая передача: предупреждение «склад общий, продукция уже там»
  для любого участка-получателя, по складам из контекста (ответ Арсена
  от 27.10), а не только для своих участков.

## 2026.10.27-1

Склады по контракту v0.4. Нужна 1С: нет, работает и на нынешней 1С;
с выходом v0.4 на стороне 1С склады включатся сами.

- Выбор участка после входа: заголовком производственный цех
  («Литейный цех · 4 участка»), если 1С его отдаёт.
- Рабочее место: остатки по складам, склад продукции первым; один склад
  на обе роли показывается одним списком.
- Новая передача: остатки склада отправки (по умолчанию склад продукции),
  выбор склада, если у участка их два; предупреждение, когда склад
  отправки и склад приёма своего участка один и тот же.
- Карточка и список передач: склад отправки и склад приёма.
- Смена: нехватка материалов по складу материалов, проверка переоткрытия
  по складу продукции.
