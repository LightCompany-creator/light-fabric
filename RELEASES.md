# Выпуски LightFabric для сервера фабрики

Первый раздел этого файла уходит в описание выпуска в GitHub Releases
(`.github/workflows/release.yml`). Новый выпуск: дописать раздел сверху,
поставить тег `v<версия>` и отправить его в GitHub.

Пометка «Нужна 1С» значит, что выпуск работает только после изменений
на стороне 1С, без них ставить не нужно.

## 2026.10.26-1

Первая боевая сборка: сервис 1С `/workf/hs/lf/v1` на serv2, приложение
`http://serv2/lightfabric/`. Нужна 1С: да, сервис должен быть опубликован,
вход учётными записями 1С.

- Запросы идут в настоящую 1С вместо заглушки.
- Скрипт обновления переписан под Windows PowerShell 2.0 (Server 2008 R2):
  WebClient, разбор ответа регулярным выражением, распаковка через .NET
  или проводник. Требует .NET 4.5+ и PowerShell на нём, см. инструкцию.
