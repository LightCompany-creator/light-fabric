# LightFabric

Цеховое приложение для планшетов на обувной фабрике Light Company.
Начальник цеха отмечает смену, выработку и передачи в соседний цех, а данные
уходят прямо в 1С: там живут справочники, остатки, документы и зарплата.
Своей базы у приложения нет.

> Как поднять, подключить к 1С и развернуть на фабрике: [`SETUP.md`](SETUP.md).
> Состояние проекта и план: [`ПЛАН_РАБОТ.md`](ПЛАН_РАБОТ.md).

## Что внутри

| Раздел | Маршруты | Состояние |
|---|---|---|
| Цеховое приложение поверх 1С | `/enter`, `/w/**` | Актуальное, идёт на фабрику |
| Старое приложение на Supabase | `/login`, `/dashboard`, `/shifts`, `/orders` | Уходит после перехода на боевую 1С |

Обмен с 1С описан в `1С-Арсену/Контракт_1С_LightFabric_этап1.md`,
ответ и вопросы к нему в `1С-Арсену/Ответ_на_контракт_v0.1.md`.

## Быстрый запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000/enter`. Пока сервис 1С не подключён, работает
заглушка по контракту: логин любой, пароль любой, для прав администратора
логин `админ`. Подключение к настоящей 1С делается одной переменной
`NEXT_PUBLIC_API_1C_URL`, подробности в `SETUP.md`.

## Стек

Next.js 14 (App Router), TypeScript, Tailwind, shadcn/ui. Обмен с 1С по HTTP,
JSON, вход учётной записью 1С. Работает на планшете как приложение,
в том числе без сети.
