# LightFabric: правила для Claude Code в этом проекте

Цеховое приложение поверх 1С, раздел `app/(1c)` и `lib/api1c`. Старый раздел
на Supabase и демо удалены 29.10.2026 (последний коммит с ними `25bb7d4`).

## Что не меняется без обсуждения

- Поведение по контракту с 1С (`1С-Арсену/Контракт_1С_LightFabric_этап1.md`
  и `Правки_контракта_v0.2.md`): что и когда уходит в 1С, статусы, отказы.
- Деньги и расценки на экране не показываются.
- Тексты на экране: факт и цифра, без инструкций.

## Связка с Claude Design

Папка `design/`. Задачи приходят в `design/ЗАДАЧИ.md`, отчёты уходят
в `design/ОТЧЁТ.md`, протокол в `design/ПРОТОКОЛ.md`.

По просьбе «возьми задачи из design»: взять задачи со статусом `новая`
по порядку, каждая отдельным коммитом, после правок проверить типы, линтер,
прод-сборку и экран в браузере, обновить снимки `design/screens/`
командой `npm run design:screens`, поставить статус и написать отчёт.
Задачу, которая ломает контракт, отклонять с объяснением.

## Проверки

`npx tsc --noEmit`, `npx next lint --dir "app/(1c)" --dir lib/api1c`,
`npm run build`, `npm run check:api1c`. Не запускать `npm run build`
при работающем `npm run dev`.
