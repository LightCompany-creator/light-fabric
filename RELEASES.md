# Выпуски LightFabric для сервера фабрики

Первый раздел этого файла уходит в описание выпуска в GitHub Releases
(`.github/workflows/release.yml`). Новый выпуск: дописать раздел сверху,
поставить тег `v<версия>` и отправить его в GitHub.

Пометка «Нужна 1С» значит, что выпуск работает только после изменений
на стороне 1С, без них ставить не нужно.
